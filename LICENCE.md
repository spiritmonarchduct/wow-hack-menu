## 🧩 About

**World of Warcraft Companion** is a curated list of World of Warcraft open-source tools:

- **Overlays** — on-screen helpers, layout notes, cooldown viewer, aura tracker
- **Quality-of-Life Helpers** — inventory catalog, mount manager, route notes
- **Research Notes** — dungeon layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Cooldown Tracker — watch ability timers at a glance
- Aura Monitor — visualize buffs and debuffs
- Combat Log Notes — record and review encounter runs
- Playback Speed — adjust review playback for study (0.1x to 5x)

### Wallhack
- Mount Catalog — browse mounts, pets, transmog sets
- Custom Profile Notes — organize character cosmetics
- Inventory Layout — improved bag and bank visibility

### Aimbot
- Dungeon Route Notes — segment study on any map
- Waypoint Control — mark and review path points
- Loot Tracker Notes — chain gathering runs in the editor
